# Advent of Code 2025 🎄

This repository contains my solutions for **Advent of Code 2026**, the annual programming challenge created by Eric Wastl.

## About

Advent of Code is a series of daily programming puzzles released every December.  
Each day brings two challenges that test problem-solving, algorithms, and sometimes your sanity. It started on Dec. 1st, 2025.

This year I solved the problems mostly in **Python**, occasionally experimenting with different approaches when the puzzles got more difficult. AI helped with brainstorming and occasional debugging, but the final responsibility for making the code work was mine, as I never allowed it to fully construct a solution for me.

## Structure
Each folder contains my solutions for both problems that were presented that day, as well as the puzzle input, and a test input. The only exception is Day 12, as it only had one task.

## Final Thoughts
It was a mix of fun puzzles and genuine brainstorming sessions. It also serves as a refresher to some programming know-hows, bringing you all the way back down to the basics - math and logic. I highly recommend this for anyone who enjoys legitimate coding challenges.
